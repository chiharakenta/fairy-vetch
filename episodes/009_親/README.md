# 第9話「親」

その時、ピンポンっとチャイムの音が鳴った。青ざめた顔をしていた美香さんは我に帰ってインターフォンに出ると、見慣れた顔が映っていた。
「あ、すいません〜遅くなりました、耕平です。耕介迎えに来ました。」
「あ...あぁ、よう来たね。ほんま良い所に来たね。どうぞどうぞ今開けます。」
バタバタと美香さんは玄関に向かっていく横で、実乃梨さんは渋い顔をしていた。
「ゲッ、私部屋に隠れとこ。じゃあね、耕介...悪い病気は、はよ治しんちゃいよ〜。」
実乃梨さんが部屋に帰っていった後に、美香さんがドアを開けると、兄がペコリとお辞儀する。
「いや〜、ほんとありがとうございます！病院連れてってくれただけじゃなくて、お昼ご飯まで...マジで助かりました。」
「ええよええよ、そんなの大したことじゃないけぇ。それより耕平くん...ウチが思ってたよりも、色々と今大変なんじゃね。ほんと、お疲れ様。」
「え？まぁ確かに、炎上気味のプロジェクトにフォローで入ってて遅くなったのは確かですけど...耕介にそんな話、したっけ？」
兄の職場において、炎上とは、状況が悪く大幅に遅れが出ている開発現場を指す。
「炎上...？まぁええわ。それもITの言葉なんじゃろうけぇ。それより耕平くん...難しいことがあったら、いつでも連絡しんさいよ。」
兄の顔を見る美香さんは真剣な表情だった。
「連絡？あぁ、まぁちょっと本家の叔父さんと話す用事があるんで、力矢さんとはどっかで相談したいとは思ってましたけど。」
本家のおじさん、ベッチの種を見つけた土地の件だ。ちゃんと動こうとしてくれていたらしい。
「あぁそうなん？今日は会社の飲み会じゃけぇ、遅くなると思うけどねぇ。」
「そっか、第三金曜は毎月そうですよね。」
「それよりどうしたん？本家の叔父さんとは、あんまり関わろうとしてなかったんじゃない？」
「そうなんですけどねぇ。ちょっと柴田さんの土地をお借りしたくて、連絡先聞こうと思ってて。」
「あ〜、あそこのお宅のことは、確かにウチらじゃ分からんねぇ。」
「やっぱそうですよね。実は最近、耕介が農業に興味持ったんで、あそこを借りて一緒に種まきしようと思ってまして。」
「種まき？...まさか。」
「ん？別に、怪しい種じゃないですよ。耕介が手に入れてきた種があって、まだ色々と調べ中ですけど、多分ヘアリーベッチっていう緑肥の種なんじゃないかなぁと思ってて...」
美香さんの顔が青ざめた。何と言ったら良いのか分からないといった顔で固まってしまう。
兄も流石に異常に気づき、こっちを向いてきた。
「...おい、耕介。まさかお前。ベッチの話したのか？」
「う、うん...友達出来たらいいねって実乃梨さんが言うから、昨日友達出来ましたって...」
「まったく...ややこしいことしやがって。」
耕介には、美香さんがなぜ青ざめた顔をしているのか、兄が何に困っているのか、全く分からなかった。
ただ、自分にとって初めて出来た友達について話しただけなのに、何か悪いことでも言ったのだろうか？
ベッチが居ることが信じられないというなら分かる。耕介だって、生まれて初めて見た生き物だ。兄も最初信じてくれるとは思っていなかった。だけど、それなら信じられないと言えば済むだけの話ではないのか。
「とりあえず、耕介はもうちょっと休んでてくれ。今度、本家の叔父さんのとこに行くから、ちょっとそれについて大人同士で相談してくる。美香さん、良いですか？」
美香さんはうなずき、二人は玄関を出ていった。パタンと閉まったドアは、耕介にとって心の壁のように感じられた。

---

玄関の外で、耕平は落ち着いて事情を説明し始めた。
「美香さん、耕介に植物の妖精とやらが見えてるのは事実です。ただ、農学的にはデタラメでもなさそうなので、とりあえずあいつが興味示したことに協力しようとは思ってます。」
「あぁ、そういうことだったんね...流石に耕平くんまで一緒に見えてるんかと思って焦ったわ。」
耕平は苦笑した。
「冗談はやめてください。俺がそんなファンタジー信じるようなやつに見えますか？」
「う〜ん、追い詰められてたら、ちょっと怖いなとは思っとったよ。あんたは、藤江ちゃんのことで誰よりも傷ついとるけぇね。」
耕平の脳内に、圃場で倒れていた在りし日の母の姿が思い浮かんだ。それを慌てて頭を振って払いのける。
「まぁ、それは事実ですが、流石に自分がおかしくなったら気付けるぐらいの理性はありますよ。」
「そう？それならええんじゃけど。」
美香さんは耕平の目を真っ直ぐ見つめる。
「それより、病院には連れて行ったん？」
痛いところを突かれてしまった。それが普通の対処法だろう。本当に妄想や病気の類なら放っておくのは危険だ。

「俺も、それは考えました。ただ……今日も気になって、AIに色々と状況を入力して相談してみたんですよ」
耕平は少し言葉を選ぶ。
「そしたら、いわゆる『イマジナリーフレンド』っていう、想像力豊かな子どもに見られる一時的なものの可能性もあるから、いきなり否定するんじゃなくて、興味を持ったことに協力してあげるのもいいんじゃないかって」
「イマジナリーフレンド？」
「ええ。それに、フェアリーっていうのも、ヘアリーベッチの名前が似てるでしょう？　どっかで俺が話したことが耕介の記憶に残ってて、それと植物の体験が混ざったんじゃないかっていう可能性もあるみたいです。」
「なるほどねぇ……」

美香さんは少し考え込む。

「じゃあ、耕平くんは、それで大丈夫だと思っとるん？」

「大丈夫、とまでは言い切れませんよ。AIは医者じゃないんでね。だけど...」

耕平は大きく息をつき、口元に力をこめる。

「あいつが...初めて農業に、ちゃんと興味持ったんですよ？」
「...そうねぇ。」

そう言うと、美香さんは黙り込んだ。美香さんも耕介の状況を知っていたからだ。
何に対しても無気力で、学校にも教会にも馴染めず、ただゲームしたり草むらを眺めて生きていた少年だった。せめて農業ぐらいは学んでほしいと、耕平があれこれ言う度に、「興味ない」「勉強やだ」と跳ね除けられてきた。
植物の妖精の登場は、もしかしたら、耕介が前を向いて生きるうえで、大きなきっかけになるかもしれない。耕平にとっても、みすみす逃す手は無かった。

「だから、俺もあいつのことを応援してやりたいし、そのためには...本家の叔父さんとも向き合うしかないと思ってます。」
「そう...あんなに叔父さんを毛嫌いしてたのに、大きくなったんじゃね。」
「いや、正直、今でも本当に行けるかどうか分からないですよ。玄関前まで行って帰るかもしれない。俺はビビリなんでね。」
「ええことよ、ビビリなんはね。農機扱うんじゃったら、それが一番安全よ。」
農機と安全と聞いて、耕平は顔を歪める。
「それが...それぐらいが、俺の取り柄ですから。」
美香さんは瞬間目を閉じて、開く。
「...分かった。それならやれるとこまでやってみんさい。ウチも応援しとるよ。ただ...」
「なんですか？」
「一回、天さんに相談しときんさい。ウチはこういう事例は何も知らんけど、牧師さんならいろんな人を見とるでしょ？病院行くにしても行かんにしても、まずは大事なことはね、親なら相談してほしいもんよ。」

天さんを親と認識したことは、耕平にはあまりなかった。確かに身元引受人ではあったし、信頼もしているが、あくまで遠縁の親戚のおじさんだ。それに、地方教会の業務は多忙を極める。わざわざ時間を出してもらうのは申し訳なかった。

「でも、あの人すごい忙しいですよ？」
「忙しくても、子どものためならすっ飛んでくるのが親っちゅうもんよ。親戚でもなんでもないウチでも、耕介ちゃんが風邪ひいてたら放っとけんかったんよ？ましてや、天さんにとっては、自分が覚悟持って引き受けた我が子なんじゃけぇ。」
覚悟を持って引き受けた我が子...確かに、天さんなら間違いなくそう思っているだろう。
「分かりました...じゃあ、ひとまず天さんに相談するってことで、一旦この件は俺が預かる形でいいですか？耕介には、今は適当に話合わせてもらっといて。」
「うん、分かった。今日中にでも天さんに連絡するんじゃったらええよ。」
耕平は顔を曇らせる。今の状況の説明文が、今日中にまとまる気が全くしない。とはいえ、美香さんが一度決めたらガンとして引かないタイプなのは、今朝の耕介連れ出しの件で分かっている。
「今日中ですか...分かりました。なんとかします。」
「うん。耕平くんも、困ったらウチでも旦那でも、いつでも頼りんさいよ。あんたはめっちゃ頭ええ天才児なのに、人頼るのがホンマ下手なんじゃけぇ。耕介ちゃんのほうがよっぽど上手よ。」
耕平は心から笑った。
「はは、それこそ、耕介はそっち方面では天才ですよ。比べられたら困ります。」
そんな天才少年を、今から連れて帰って、いつも通り晩御飯を食べさせないといけない。
耕平にとっての夜は、始まったばかりだった。
