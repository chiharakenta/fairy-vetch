# 第10話「仲間？」

お腹が空いたので、みかんジュースを飲んでいたら、ようやく兄と美香さんが戻ってきた。
「あ、おかえり〜。」
よその人の家だというのに、ついいつもの調子で耕介は挨拶した。
しまったと思ったが、美香さんがニッコリ笑って
「ただいま〜。」
と答えてくれた。
「ごめんね〜、耕介ちゃん。ちょっとウチ、妖精の話が信じられんくて、パニックになっとったわ。でもまぁ、耕平くんの話聞いたら、案外居てもおかしくないかもしれんな〜って思えてきたわ。」
「あ、な〜んだ。そうだったんですね。兄ちゃん、ありがとう！」
どうやら、兄はベッチについて説明してくれていたらしい。いつも都合の悪いことは「大人の話」と言って仲間はずれにする兄だったが、今回はちゃんと自分の味方をしてくれたと思うと胸が暖かくなった。
「おう、まあプレゼンは俺の得意技だからな。」
照れ隠しに兄は鼻をこすっていた。
「それより、そろそろ帰るぞ、耕介。腹も減ってきたろ？」
「うん！めちゃくちゃ空いた！」
「はは、食欲は大丈夫みたいだな。いやほんと、美香さんが病院連れて行ってくれたおかげです。」
美香さんが笑う。
「まあね〜。大体子どもいうんは、病院行ったらそれだけで安心して治るもんなんよ。」
「まあ割と、そういうとこありますよね。」
そう言うと、兄はテーブルの上のみかんジュースに目を留めた。
「おい...これまさか、耕介、買ってもらったのか？」
「うん。病院行くついでに買ってもらったよ〜。」
「お前、ちゃっかりしてるなあ。このジュース、地味にお高いやつだぞ。」
「え？そうなの？」
ふと美香さんの方を見ると、耕平を見てニヤリと笑っていた。
「ふっふっふ、そうなんよ〜。どうしよっかな〜ツケとこうかな？」
「いやすぐ払いますよ。ジュース代ぐらいは流石にね。」
美香さんは大手を振るう。
「冗談に決まっとるでしょうが。朝言うたとおりよ。その分、今度の子ども食堂にでもなんか買って持っていってあげんさい。」
「なんかすいません...」
「出た！藤江ちゃんとおんなじ『すいません』！ここはありがとうでええんよ。」
「はい...ありがとうございます。」
「それより、次に教会で子ども食堂やるのはいつ頃なん？だいたい月末の土曜のイメージじゃったけど。」
「そうですね。来週の土曜日の昼になりそうです。」
「なぁんだ。それならその時にでも天さんにすぐ相談できるか。」
耕平は首を横に振る。
「いや、だいたいあの人、土曜日は丸一日説教準備するから無理だと思います。」
「説教？あ、そうか...なんか礼拝で話す内容を準備するんじゃったね。」
説教とは、教会の日曜礼拝で話す牧師の話のことだ。叱りつけるお説教ではなく、文字通り、聖典の"教え"を"説く"ものだ。天さんの牧師の仕事の中では、一番重要と言っても過言ではない。
「そうです。だからどっちみち、俺から良い感じに連絡しときますよ。」
それを聞いて、天さんに連絡する用事があったのか耕介は思い返してみる...パット思い当たらなかった。
「あれ、なんか連絡しなきゃいけないことってあったっけ？」
兄が少し考えてから答える。
「ほら、自立する前に言ってたろ。『時々そっちの生活状況も聞かせてね〜』って。もう実家戻って3ヶ月経つからな。そろそろ状況報告しとこうと思ってな。」
「ああ、なんかそう言ってたね。兄ちゃんやっぱ記憶力良いなぁ。」
「そこは俺、自信あるからな。」
兄がふふんと鼻を鳴らす。
「うわ、えらそー。」
そんな軽口を叩きながら身支度をしていると、
「ほんと、エラソーだよねぇ！メガネの兄さん。」
廊下の部屋から実乃梨さんが出てきた。
「なんだお前...居たのか。」
「なんだはないでしょ。ここ私のおうち！偉そうな奴特有のいや〜なオーラ出てたよ。」
「何がオーラだ。青春スポーツアニメでもずっと見てたのか？」
実乃梨さんの動きがピタリと固まると、耕平がニヤリと笑う。
「図星だったか？」
「別に...部活やってんだから普通でしょ。」
「そうだな。普通だな...ま、俺がお前ぐらいの時はとっくにアニメ卒業してちゃんとお勉強してたけどな〜。」
実乃梨さんが怒り出しそうなので、耕介はすかさず突っ込む。
「でも兄ちゃん。大学行ってからやけにアニメ詳しくなって帰ったきたよね...？」
「おいばか！それを言うな。それは研究室のオタクに付き合わされてただけだ。」
「ほんとぉ〜？結構アニメの話してるとき楽しそうだったけど。」
実乃梨さんが勝ち誇った笑みを浮かべる。
「な〜んだ、一緒じゃん。どうせ、アニメキャラみたいに、メガネが本体とかお友達に言われてたんじゃないの〜？」
ちょっと前のギャグアニメに、確かそんなキャラクターが居たはずだ。
「悪いが、そーいう大衆向けのアニメじゃなくて、もっと昔の名作掘り出して鑑賞会するようなやつだった。」
耕介の頭の中に、「名作鑑賞会」「古い作品」という言葉が残る。となると、そのお友達とやらは...
「え？それってガチじゃん。」
兄にたまらずツッコミを入れる。わざわざ古いアニメを掘り出すのは、相当なアニメオタクに違いない。
「そうだ。ガチオタクだ。」
「だからかぁ。なんか夏休み帰ってきた時、古い魔法少女もののアニメの話してたの。」
それを聞いた瞬間、実乃梨さんがゲラゲラと笑い出した。
「ウケる〜！そんな偉そうなナリして、魔法少女とか見てたの！？」
「違う！見てたのは事実だが、本当に付き合わされてただけだ！！」
「一緒一緒！私とか母さんよりよっぽどマニアじゃんか〜！」
黙っていた美香さんが横から割り込んでくる。
「実乃梨、ちょっとええ？人は見かけで判断しちゃいけないって言うでしょう？アニメもね。見かけとかジャンルで判断しちゃいけんのよ。魔法少女アニメでも、深いメッセージ性があったりするんだからね。」
兄が目を見開く。
「美香さん...まるで、俺の友達みたいなこと言いますね...もしかして、結構アニメ見てました？」
美香さんがフフッとミステリアスに笑う。
「女子高生がね。月の光のパワーで変身するアニメ見とったわ。」
「マジすか！？妖怪のアニメとか、ほのぼの系ばっかりだと思ってましたよ...」
実乃梨さんがキョトンとする。
「え、なにそれ？月の光で変身？」
美香さんが諭すように言う。
「実乃梨、あれはね。子どもにはまだ早いんよ。」
「あ〜！都合の悪い時はそうやって子ども扱いする〜！」
「あんたも都合の良い時だけ、子どもの立場使（つこ）うとるでしょうが。」
実乃梨さんは、何も言い返せずぐぬぬと口を結んでいた。
美香さんが神妙な面持ちで兄に尋ねる。
「耕平くんがお友達に見せられた言うのは、何？」
「あれです。女の子が散らばったカードを集めるやつです。」
「それは...名作じゃね。」
「分かってくれますか。」
二人はエアで拳を突き合わせた。

実乃梨さんが困惑する。
「え...なにこれ。その...何？」
耕介は自信満々に答えた。
「これが...友情ってやつですよ。」
「うん、それ絶対違うと思う。なんかもっと濃い何かだよこれ。」
美香さんが満足げに微笑む。
「実乃梨にもきっと...分かる時が来るはずよ。」
「嫌だ！なんかよくわかんないけど絶対分かりたくない！わかんなくていい！！」
実乃梨さんが怖いものを見るように自分の部屋へと逃げていった。
意味はよくわからなかったが、その会話が面白すぎて耕介はお腹を抱えて笑っていた。
釣られて兄と美香さんも笑い出す。
ひとしきり笑った後に、魔法少女という言葉と、夢で見た女の子の姿が重なる。
「あ、もしかしたらベッチも魔法少女かもね。増えたら魔法使えるとか言ってたし！」
瞬間、びくっと美香さんの体が震えたが、すぐにまたミステリアスな笑みに戻った。
「そうじゃね...耕介ちゃんが同志になる日も、近いかもしれんね...」
兄がすぐさま答える。
「いやそれは流石に嫌です。耕介には純粋なままで居てほしい。」
「うん...まぁ確かに、耕介ちゃんはそれがええかもしれんね。」
大人二人のよくわからない言い回しに耕介は混乱した。
だけど...さっき、ドアを隔てられた時と違って、不思議と心地よいものだった。
