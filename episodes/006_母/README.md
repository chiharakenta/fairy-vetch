# 第六話「母」
ピピピ、と体温計が鳴りだす。
脇から取り出すと、ディスプレイに映し出された数字は37.1。

（やっべ...）

昨日の夜、大冒険から帰ってくると、耕介はいつものように遅くまでスマホで動画を見てから眠りに就いた。
それでも、普段は兄の朝ごはんの呼び声で目を覚ますが、今朝は妙に体がだるく布団から出られなかった。
その理由が、体温計のディスプレイにありありと表示されている。

（兄ちゃん、仕事中かな？）

動けないほどではないので、兄の自室のドアまで行って聞き耳を立ててみる。

「...ですね。今日は外部APIを使って認証機能を一通り実装して...」

どうやら、朝のミーティング中のようだった。
兄は普段、自宅でパソコンを使って仕事をしている。最近よく聞くプログラミングというやつだ。
ミーティングもオンライン会議のソフトを使って、東京や大阪の人と話すのだと聞いたことがあった。
よくわからない言葉も、おそらく仕事の専門用語なのだろう。

普段は仕事時間中でも好きに話せるが、ミーティング中に話しかけるわけにはいかない。
相変わらず体はだるいので、ゆっくりリビングのテーブルまで移動する。
テーブルの上には付箋が置いてあった。

"肉じゃがののこり、れいぞうこにあります。"

書き置きに従って冷蔵庫を開けると、中には皿に盛られた肉じゃががあった。サランラップの封もしっかりしてある。
あまり食欲は無かったが、それでも全く食べないわけにはいかない。
レンジで600Wにメーターを合わせ一分半ほど加熱する。

待っている間に、レンジの先から香ばしい香りが広がってくると、少しだけ、耕介は空腹感を思い出した。


ピーッとレンジの音が鳴った。
やけどしないよう、キッチンのミトンを両手にはめて皿を取り出す。
ラップを剥がしてみると、よく味の染みた良い色の肉じゃがと、今朝追加で割り入れたであろう卵が光る。

皿から立ち上る香りを鼻いっぱいに吸い込むと、耕介の腹がぐぅと鳴りだした。
急いで茶碗を取り出しご飯を盛って、肉じゃがと一緒にテーブルまで持っていく。

「いただきます」

両手の指を交互に組んで、一人でつぶやく。
誰が見ているわけでもないが、自然に身についた習慣だった。


大きめのじゃがいもの切れ端をふうふうと冷ましながら、口元に運んでいく。
「あちちっ！」
一口が大きくて、中の方がまだ熱かった。
慌てて水を飲んで舌を冷まし、慎重に食べていく。

ゴクンと飲み込むと、体の奥が少しあたたかくなった気がした。
二口、三口と食べていくにつれ、だんだんと体のだるさが収まっていく。

肉じゃがが無くなると、ご飯だけが残ってしまった。
じゃがいもの割合が大きいので、ご飯のおかずとしてはどうしても少なく感じる。
兄は納豆を食べているが、耕介は匂いが苦手なので、キッチンにある棚から海苔と卵のふりかけを取り出す。

（やっぱこれだよね〜）

兄は小魚系の方が体に良いと言っていたが、耕介はこのふりかけがお気に入りだった。
兄も欠かさずに補充しておいてくれる。

ガツガツとお気に入りのふりかけご飯を平らげると、体のだるさはなくなった。
ただ、やっぱり頭がぼうっとするので、皿をシンクに置くと、後は部屋で寝ることにした。

シンクから自室に歩き出したその時、
「ピンポン」
とチャイムが鳴った。

兄の部屋の方を見ると、まだミーティング中なのか出てくる気配がなかったので、耕介は自分で出ることにした。

「はいは〜い」

ドアを開けると、見慣れた近所のおばさんだった。

「耕介ちゃん！よ〜帰ってきたね！大丈夫だったん？」

「あ、美香さん！ごめんなさい、心配かけちゃって。」

家の近所の吉田美香さん。
生まれも育ちも広島県民なので、聞き馴染みのある訛りだった。

「心配なんてええよ〜。それより、耕平くんに叱られなかった？」

耕介は苦笑いする。

「流石に怒られちゃいましたよ。門限破って何やってんだって。」

「ありゃまぁ。」

すると、美香さんは口を尖らせた。

「耕平くんったら人のこと言えないでしょ〜。うちの旦那も山駆け回ったんだから...」

おそらく、昔兄が本家のおじさんの家を飛び出した時のことだろう。
最終的には力矢おじさん、吉田力矢が兄を助けてくれたと聞いたことがある。
耕介自身はなんとも言えず笑っていると、

「あれ、耕介ちゃん。体調悪いの？」

見抜かれてしまった。

「え？なんで分かったんですか？」

「そりゃ分かるよ〜！なんか顔色悪いし、返事も元気ないもん。」

美香さんはいつもそうだった。
何も言わなくても、ほんの少しの異変を察知する。
お母さんというのは、みんなそうなのだろうか。

「風邪ひいちゃったの？」

「多分そうです。熱は大したことないんですけど、昨日の夜ちょっと寒かったんで。」

美香さんは手に持っていたビニール袋を申し訳なさげに差し出す。

「ごめんね〜、プリン持ってきたんだけど、あんまり冷たいものは良くないよね...」

耕介は目を見開いた。

「いや、プリンは食べます！」

「...元気そうじゃね。」

美香さんは苦笑いして、プリンを手渡してくれた。
スーパーで売っている、底面のピンをプッチンっと折ると出てくるタイプのプリンだ。

両手で受け取ると自然に笑みが溢れる。
プリンはどんな匂いなのか気になって袋を覗き込むが、急に鼻がむずむずしてきた。

「ぶえっくしょん！」

顔をそっぽに向けてくしゃみを吐き出すと、ブルブルと体に寒気が走り出す。
美香さんが心配そうにこちらを見つめる。

「病院は行った？」
「いえ、まだです。」
「耕平君はどこにおるん？」
「今、部屋で仕事中です。」
「そっか...今はおうちで仕事できるんじゃったね。」

「そうなんですけど、今ミーティング中みたいで。」

美香さんが目線を上に向けて思案する。

「そりゃぁ困ったね...病院、連れてってあげよっか？」

「え、でも、大丈夫なんですか？」

吉田家には、娘さんが一人居るはずだ。

「どうせ光(ひかり)は高校行っとるけぇ、今の時間なら大丈夫よ。」

そうだった。さっきリビングで見た時計は、10:50頃を指していた。
耕介と違って、普通の子どもは学校に行っている時間だ。

どうしようか考えていると、後ろからドタドタと廊下を歩く足音と、兄の声が聞こえてきた。

「あ、美香さん！すいません、昨日は心配かけてしまって...」

美香さんは陽気に答える。

「あはは、二人しておんなじこと言ってから。全然ええよ〜。それより仕事は大丈夫なん？」

耕平は一瞬考えて答えた。

「ミーティングは終わったので、次の12:00までなら大丈夫です。」

「へ〜、仕事中に抜け出してええもんなん？」

「ITなんて、やることやってたら誰も文句は言いませんよ。」

「はぁ〜、そういうもんなんか。今どきの子はすごいねぇ。」

耕平は少しだけ誇らしげな顔をした。
そのまま耕介を見ると、持っているプリンに気がついた。

「あ、わざわざ買ってきてくれたんですか！ありがとうございます。」

「いやいや、それはええんじゃけど...」

美香さんは眉根を寄せると耕平に言った。

「耕介ちゃん、風邪ひいとるみたいよ。」

「え？」

耕平は耕介の顔をまじまじと見る。顔色が悪いのを耕平も感じ取ったのか、

「お前...だから夜ふかしは程々にしとけって言ったのに。」

ため息まじりにつぶやいた。
心配してくれない兄に対し、耕介もそっぽを向いて言い返す。

「夜ふかししてもしなくても、どうせ風邪ひいたもん。」

「またそうやって屁理屈言いやがって...」

美香さんが一言釘を差す。

「屁理屈は耕平くんのお得意技でしょ？」

兄は、悔しそうな顔をするだけで何も言い返せなかった。
美香さんが続ける。

「とりあえず、これからウチは耕介ちゃん病院連れてくけえね。」

耕平が慌てる。

「いや、それは流石に...俺が適当に、午後から中抜けすればなんとかなりますよ。15時ぐらいからなら動けますし。」

「今更何言うとるの？耕平くんだって耕介ちゃんのために稼がんといけんでしょ？」

「それは...そうですが。」

耕平は言葉に詰まる。
そんな耕平の顔を美香さんは真剣に見つめたかと思うと、ふと地面に目を落とした。

「それにね。ウチだって、藤江ちゃんのためにも出来ることはしたいんよ。」

兄は何も言い返せず、黙り込んでしまった。

――畠山藤江（はたけやま ふじえ）
母の名前だ。
耕介にとっては、あまり顔が思い出せず、墓に刻まれた文字としてしか知らない。

黙り込んだ兄が何を思っているかは分からない。
しかし、今のままでは兄が困ってしまうということだけは分かった。
耕介の口が自然に開く。

「俺、早く病院行って薬もらいたい。」

そう言って笑って兄を見つめる。
すると美香さんも満面の笑みを浮かべた。

「そうじゃねぇ、耕介ちゃん。はよ行こっか。」

そのまま耕平の方を見る。

「そういうことじゃけぇ、病院連れてくね。」

耕平も渋々頷く。

「...分かりました。あとでレシートだけ持ってきてください。」

美香さんは深いため息をつくときっぱり言った。

「びた一文要りません。今度、子ども食堂行くときにでも取っときんさい。」

そう言うなり、美香さんは車を取りに家へと帰っていった。

ただ突っ立っている兄の姿は、二十歳（はたち）にしては随分と幼く見えた。
