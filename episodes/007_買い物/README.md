# 第7話「買い物」
ブルブルとしたエンジン音が聞こえて玄関口を出ると、白の軽自動車から美香さんが出てきた。
「待たせたね〜、ほんじゃ行こうか。」
「お願いします！」
兄に持たされたマスクを渋々付けて、耕介は車の助手席に座った。
力矢おじさんが乗っている中型の自動車には前に乗せてもらったことがあるが、軽自動車のほうに乗せてもらうのは珍しく、車内の景色が気になって見渡していた。一昔前の車なのか、車内にはガソリンと人の匂いの混じった独特の香りが漂っていた。
助手席の窓の近くにある取っ手には、招き猫のようなぬいぐるみがぶらさげてあった。
「美香さん、これってなんですか？」
「あぁ、これねぇ。」
美香さんは、慣れた手つきで車を発進させると、半笑いになりながら答える。
「ウチの大好きなアニメに出てくるキャラクターなんよ。主人公に先生って呼ばれててね、実はぶち強い妖怪よ〜。」
「あ、知ってるかも。妖怪の名簿みたいなのが出てくるやつですよね？」
「よ〜知っとるね！見てたん？」
「いや、ちゃんと見てはいないんですけど、動画サイトでなんか見かけました。」
「ありゃ〜、見とったんなら色々語りたかったじゃけどねぇ...」
残念そうな顔をしながら美香さんは運転を続ける。

しばしの沈黙が訪れている間、耕介は窓の外に映る田んぼの景色を眺めていた。温かな日差しを浴びた稲が、青々と茎を伸ばしている。
風に揺れる度、白い光が水蒸気の霧のようにほとばしっているのが耕介の目には見えていた。
草の光を眺めていると、自然の音も聞きたくなってきた。
「窓、開けてもいいですか？」
「もちろんええよ〜。エアコン切って開けようか。」
美香さんがスイッチを押すと機械音と共に窓が開く。マスクを下にずらして新鮮な空気を胸いっぱいに吸い込むと、稲の青い香りが鼻に入り...
むずむずしてきた。
「ハックションッ！」
やっぱり、今は自然の演奏会を聞いている場合ではないらしい。
耕介はマスクを鼻まで戻して、慌てて助手席の窓を閉める。
「ま、元気になってからのお楽しみじゃね。」
そう言うと、美香さんは再びエアコンのスイッチを入れて、運転席側の窓も閉めた。

「それにしても、耕介ちゃんは田んぼの風景好きなんじゃね。そこはお父さん譲りかもしれんね。」
「お父さん...ですか。」
耕介にとって、父との記憶もあまり残っていない。
かろうじて残っているのは、父が田んぼに撒いたレンゲの花を一緒に眺めていたことだ。
小さく可憐な花が咲き、その上をミツバチたちが飛び交う原風景。それを一緒に眺めながら父は、きっと笑っていた。しばしの間、耕介は懐かしい感覚に浸る。

「逆に、耕平くんはほんとお母さんにそっくりじゃね。」
美香さんがぽつりと言う。
「お母さん...ですか？」
「そう！ほんと耕平くんみたいな真面目な子よ。ウチと違って、学校の宿題は家帰ってすぐやりよったし、責任感も強(つよ)うて"すいません"が口癖じゃった。」
「へぇ〜。」
顔も思い出せない母にも、子どもだった頃がある。当たり前のことだが、それを知っている人が居ることが耕介にとっては不思議に思えた。
「耕平くんは勉強も仕事もできるし、家事もちゃんとやっとるからねぇ。偉いと思うよ。ウチじゃったらそこまで出来んわ。家事も休みの日には旦那に押し付けとるからね。」

ハンドルを握る美香さんが前を見つめたままニヤリと微笑む。釣られて耕介も苦笑する。

「ははは。でもまあ力矢おじさんなら喜んでやってくれるんじゃないですか？」
「それが、普段はええんじゃけどね...機嫌悪い時は中々動かんでから、結局ウチがやることも多いんよ。」

本当に困ったものだと言いたげに、美香さんはため息をついた。耕介にとっては、いつも親切な力矢おじさんでも、家族から見るとまた違った面があるのだろうか。美香さんが家事を押し付けているというのも驚きだったが...

「でもまぁ...親子揃って真面目すぎるのは困ったもんじゃねぇ。」
そう言って、美香さんは目を細める。
「なんでも自分で抱えちゃいけんよ。体壊してしまう。」
口調こそいつも通りだったが、言葉の奥に、昔を懐かしむような重みを感じさせた。
耕介はどう返せばいいか分からなかったが、美香さんが続ける。
「お父さんがおらんようになってから、藤江ちゃんったら寝込んでしもうてね。ウチが行っても会いたくないって言うて...」
初めて聞く話だった。耕介は、ただ口を半開きにしたまま黙って聞いていた。
美香さんが慌てる。
「あ、ごめんね！ついつい話し過ぎてしもうた。話が長いって実乃梨にもいっつも言われとるけぇね...それより、飲み物買(こ)うてあげようか？」

耕介の顔がぱっと輝く。
「いいんですか？」

美香さんがこういう時は、大抵、耕介の大好きなジュースを買ってもらえるパターンだ。

「ええよええよ。スーパー近いしね。言うても、風邪ひいとるけぇジュースじゃなくてポカリぐらいしか買えんけど。」
「え、ジュース、駄目なんですか？」

運転席の美香さんをじっと見つめると、困った顔が浮かんでいた。

「う〜ん、駄目じゃないけど...果物ジュースぐらいなら耕平くんも許してくれるかな〜。」
「じゃあ、それでお願いします！」

ジュースが買ってもらえると聞いて、耕介は両手を握って喜んだ。
「ジュース〜♪ジュース〜♫」
拳を胸の前に持ってきて、リズムよく左右に揺らす。

「はは！耕介ちゃんはええね、絶対商売上手になるよ。」

そう言うと美香さんは、スーパーの方向にウィンカーを出して、曲がり道を左折した。

---

スーパーの駐車場に入ると、美香さんが尋ねてきた。
「どうする？風邪っぽいなら、車で休んでてもええけど。」

耕介は少し考え込んだ。確かに時々くしゃみは出るし、頭もはっきりとはしていない。それでも、体がだるいというほどではなかった。何よりも、お目当てのジュースを買ってもらうためには...

「そんな体しんどくないので、一緒に行きま〜す！」
「おっけー、りょーかい！」

車が駐車場に止まり、美香さんと一緒に降りると、店の看板が目に入る。

―――ドリーム・シティ

耕介たちの住む報瀬（しらせ）町ではおなじみのスーパーだ。広島市内には、大型のものもあるらしい。
店内に入ると、クーラーがよく効いていて、少し寒気がした...体がブルブルと震える。
それを見て、美香さんが心配そうに見つめてきた。
「買い物、早めに済まそうね。」
コクンと頷き、飲み物コーナーに行くと、耕介の大好きな炭酸ジュースが並んでいた...が、それを横目に美香さんは通り過ぎていく。案外、ペットボトル入りの果物ジュースは多くない。耕介も名残惜しいが見送るしかなかった。
冷蔵コーナーは見送り、常温のコーナーに行くと、一回り大きめのボトルのみかんジュースが見つかった。耕介が何も言わず見つめていると、察した美香さんが声をかける。
「これがええの？」
「はい！」
「やっぱ耕介ちゃんは目の付け所が違うねぇ。中々ええやつ選んだじゃないの。」
美香さんは、みかんジュースをカゴに入れた。
「あ、そうそう、耕平くんもコーヒーとか要るかねぇ？」
「あ〜...兄ちゃんコーヒーの味は好きだけど、ノンカフェインじゃないと駄目って言ってた気がします。」
家に置いてる豆も、確か通販で買ったノンカフェインで揃えていたはずだ。
「流石にそれはスーパーには無いね...まぁ、ええじゃろう。さっき渡したプリンでも食べてもらえば。ね？」
伺うように美香さんは耕介を見つめる。
家でもらったプリンは3個セットになっていた...兄に一個ぐらいなら渡しても大丈夫だ。耕介は頷いた。
その答えに安心したのか、美香さんはレジまで行って会計を済ませる。ただ、財布ではなく、スマートフォンを取り出して店員さんに見せていた。
「あれ？QRペイってやつですか？」
最近は兄もよく使っている、スマホアプリの決済サービスだ。
「そうそう！ポイント還元に惹かれて始めたんじゃけど、これが普通に便利でね〜。旦那は現金じゃないと落ち着かんとか言うけど、ウチはもういっつもこれよ。」
出口まで歩きながら話を続ける。
「へぇ〜。兄ちゃんが"UXが良い"とか言ってたけど、やっぱ便利なんですね。」
「ユーエックス？なにそれ？」
「えっと、なんだっけ？...確か、使い勝手が良いってことらしいです。」
「ああそういうこと。ITは専門用語が多くて分からんね。確かに、このアプリ使いやすいけどね。チャージも一瞬で出来るし。」
「いいなぁ。今度兄ちゃんに言って入れてもらおうかな。」
「ええね。耕平くんなら詳しいし、簡単に設定してくれるじゃろう。」

スーパーを出ると、むわっとした6月の湿気が肌に張り付いてきた。それでも、冷房のかなり効いた店内に居たので、少し暖かくも感じる。
「はい、耕介ちゃん。」
美香さんにジュースを渡されると顔がニヤけてきた。早速開けてごくごくと飲むと、果汁100%の濃厚なみかんの味が心地よく、体に染み渡る感覚がある。
「そんなに美味しそうに飲んでもらえると、おばちゃん嬉しいわぁ。実乃梨は当たり前みたいな顔しとるからね。」
飲んでいる最中だったので美香さんに返事は出来なかったが、遠慮なくわがままを言える母親が居ることに、耕介は少し羨ましさも感じていた。
全体の10%ぐらい飲んだところで、一旦蓋をしたが、段々と喉に熱さを感じてきた。
「ゴホッゴホッ！」
少しだけ、みかんの濃厚な味が喉に染みた感覚がする。美香さんが心配そうにこちらを見る。
「あちゃ〜、そうか。ちょっと柑橘は良くなかったかもねぇ。喉がピリピリしたんかも...はよ車乗りんさい。病院まであと少しじゃけぇ。」
美香さんに促され、耕介が車に乗り込むと、二人は病院への道のりを走り始めた。
