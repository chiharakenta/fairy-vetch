# 第8話「友達」
「良かったねぇ耕介ちゃん。ただの軽い風邪で。」
そう言いながら美香さんが昼ごはんの皿を片付け始める。

内科で診察をしてもらったところ、軽い風邪だったらしい。診察が終わった途端、耕介の体は嘘のように軽くなり、頭もはっきりとしてきた。それから、美香さんが兄に連絡を送り、仕事が終わるまでは美香さんの家、吉田家で休ませてもらうことになったのだ。
「美香さん、ごちそうさまでした。鮭と卵焼き美味しかったです！」
「ほんま？朝の残りだったけど、そう言ってもらえると嬉しいねぇ。」
手際よく片付ける美香さんの横で、耕介は病院でもらった食後の風邪薬を飲んだ。舌に苦い後味が残る...みかんジュースを飲んで、それを打ち消した。

「和室に旦那の布団敷いといたから、そこでちょっと休みんさい。」
「は〜い。」
耕介は布団に入り込むと、自分の布団とは違う香りを感じた。自分の布団も、気づかないだけで匂いがあるのだろうか？そんなことを考えながら目をつむると、頭がぼんやりしてきた。
病院を出てからすっかり元気で、あまり眠くはなかったが、薬の影響かもしれない。

段々と考えが曖昧になっていき...

~~~

気づいたら、耕介はいつもの草むらに立っていた。

草むらに一陣の風が吹くと、誰かが指揮を取っているみたいに、草たちがざあざあとささやく。
視界はあまりはっきりとはしない、宙に浮いているような感覚だったが、自分が畑に居ることだけはなんとなく分かった。
ただし、周りを見渡してみると畑の隅の小さな一角ではない、だだっ広い大きな畑だった。揺れている草も、みんな同じ種類だ。ふさふさと伸び始めたつるが地面をあまねく覆っている。
その中心には、薄紫の髪色をした手のひらサイズの少女の後ろ姿が見えた。背中には、地面に生えている草の葉っぱと同じ色・形をした羽が生えている。ひらひらと羽ばたくと、少女は宙に浮かんでいった。
（こんな子...畑に居たっけ？）
この世のものとは思えず、ただ呆然と眺めていたが、少女がくるりと振り返ってこっちを見た。
あどけない丸い目をジッとこちらを向けて見つめている。初めて見る顔だったが、耕介は、なぜか見覚えがあるような気がした。
すると、ふっといたずらっぽく微笑み、耕介の頭に響く声で言った。

「待ってるよ...コースケ。」

その声には...聞き覚えがあった。

~~~

「ただいま〜！」

よく響く声が、耕介の目を覚ました。
ドタバタと玄関口から音が聞こえてきて、耕介は起き上がる。

リビングの美香さんが挨拶を返す。
「おかえり〜！今、お客さん来とるよ〜。」
「お客さん？」

高校の制服を来て、重そうなカバンを背負ったお姉さんがリビングに現れ、和室の方を見る。
「あれ？耕介じゃん。来てたんだ。」
「実乃梨...さん？」
「久しぶり〜。どしたの？急にうち来て。」
「ちょっと風邪ひいちゃって、休ませてもらってたんです。」
「あ〜そうなの？大変だね...しかも、お父さんと同じ布団かぁ。かわいそ。」
美香さんの眉が吊り上がる。
「そういうこと言うんじゃないの。」
「だって〜、ゴリラみたいな匂いするじゃん。」
「あんたゴリラの匂い知らんでしょうが。」
そこまで言うと、実乃梨さんは無視して自分の部屋に荷物を片付けに行った。

実乃梨さんを見るのは本当に久しぶりだった。天さんのところを独り立ちして、報瀬に戻ってきた時、一度吉田家に挨拶に来たが、その時は家に居なかったからだ。兄に比べると、この6年でなんとなく顔立ちも変わった気がする。
「なんか雰囲気、変わりましたね。」
「そう？根はいつまで経っても子どもなんじゃけどね。」
すると、廊下の方から反論の声が届く。
「誰が子どもだってぇ？」
「うわ、変なところだけよう聞いとるんだから。」
美香さんが頭を抱えると、荷物を下ろした実乃梨さんが戻ってきた。
「ちょっとお母さん。耕介の前では良いお姉さんで居たいんだからさぁ。そういうこと言うのやめてもらっていい？」
「子どもであることは否定せんのじゃね。」
「あ、いや...私別に子どもでもないし〜？」
「もう遅いわ。」
実乃梨さんが悔しそうに口をぎゅっとつぐんだ。見かねて耕介はフォローする。
「いや、まぁ実乃梨さんは良いお姉さんだと...」
言いかけたが、面倒見てもらっていた幼少期の記憶はあまり無い。
「思い...ます。」
美香さんが実乃梨さんを向く。
「あんた、これ絶対言わせとるよ。」
「うん...なんかごめんね、耕介。」
変な空気になってしまった。
「いや、俺は別に気にしてないですけど...」
「あ、ほんと？じゃあいいや。」
実乃梨さんは立ち直りが速かった。

「それより耕介、お兄さんと二人で暮らすのってさ、大変じゃない？メガネの兄さん、細かいことうるさそうだし。」
兄は昔からメガネをかけていた。いつの間にか、実乃梨さんの中ではメガネの兄さんで定着していたらしい。
「まあ兄ちゃんは結構そういうとこありますけど、俺も好き勝手やってるからなぁ。」
「小学生ならそんなもんでしょ。まあ、私も好き勝手やってるんは一緒だけどね〜。」
美香さんがため息をつく。
「あんた...自覚はあったんじゃね。」
「だって子どもだも〜ん。」
「都合の良い時はそう言うんだから。」
実乃梨さんはおもむろに立ち上がると、冷蔵庫の麦茶をコップに注いでごくごくと飲み干す。ふぅっと一息付くと、下を向いたままつぶやいた。
「なんか、最近のメガネの兄さん、近寄りがたいオーラ出てんだけどさ、耕介何か感じない？」
「オーラ？う〜ん、草のオーラ以外、俺見えませんよ。」
「え？草のオーラ？...なにそれ、ちょっと早いけど、耕介ってそういうお年頃なの？」
しまった。草の生命力が光として見えるという話は、美香さんと力矢おじさんにしか話していなかった。どうやら実乃梨さんまで伝わってはいなかったらしい。どう説明したらいいか悩んでいるとすかさず美香さんがフォローする。
「耕介ちゃんはね、芸術家タイプなんよ。そういう表現よ表現。」
「あ〜、そういうこと？なんか部活のめっちゃ上手い先輩も言ってたわ。強い選手はオーラがあるとかなんとか。」
どうやら、納得はしてもらえたらしい。
「そうそう、そういうこと。ってかオーラとか言い出したのはアンタでしょうが。」
「そうだっけ？あ、そうそう。メガネから出るオーラの話ね。」
耕介の頭に疑問が浮かぶ。
「メガネからオーラが出てるんですか？」
「う〜ん、多分そう。きっとそう。」
近寄りがたいオーラの発生源がメガネだとしたら、外せば出なくなるのだろうか？疑問は尽きない。
そんな、口を半開きにして考え込んでいる耕介を見て、美香さんが耳打ちする。
「この子は結構その場のノリで喋ってるから、あんま深く考えんでええよ。」
状況はよく飲み込めない耕介だったが、とりあえず頷いた。実乃梨さんが不満げな顔をする。
「またなんか私の悪口言ってるんだろうけど...まあいいや。メガネの兄さんさ、なんか変じゃない？生き急いでるっていうのかな。何にそんなにせっせかせっせか追われてるんだろうって感じ。大学も3年で卒業したらしいじゃん。何？人生攻略RTA走ってる？」
RTAとは、ゲームの世界でエンディングまでの早さを競う競技、リアルタイムアタックのことだ。
美香さんがすかさず反論する。
「アールティーエー...？ってのはよく分からんけど、別にええことじゃないの、飛び級なんて。あんたも見習いんさい。」
「いや、そういう話じゃなくってさ。」

実際、周囲の人の話を聞く限りだと、兄は相当頭が良いらしい。高校に通わずに、16歳で高校卒業認定を受け、17歳で大学に入学した。
大学も本来は4年かかるらしいが、1年早く卒業し、今は20歳で働き始めている。
...単純に教室に入れず遊んでるだけの自分とは大きな違いだ。

「私が言いたいのは、いくらなんでも色々と飛ばしすぎじゃない？ってこと。なんか、昔はもっと落ち着いた感じだったと思うんだよね...まあ細かいことで講釈垂れるのは、昔の方が自慢っぽくてうざかったけど。」
「あんた、最近耕平くんとは話してないでしょうが。」
「だって、近寄りがたいんだもん。」
「そんなこと言わんの。二十歳（はたち）で仕事して家事までやっとるんだから、立派でしょうが。」
「それこそ変だよ。今流行りのリモートワークでしょ？だったら、清上（せいじょう）の牧師さんのとこにずっと居ても良かったじゃん。」
「まぁ、天（そら）さんのとこにおったほうが普通は安心ってのは...そうじゃねぇ。」
「でしょ？」
美香さんは黙ってしまった。いつの間にか、耕介を置いて色々と話が進んでしまっているが、実際、天さんは自立を促すことはなかった。今年の3月に故郷に帰る決断をしなければ、一緒の生活を続けることは可能だっただろう。
「耕介はさ、今も学校、行ってないんだっけ？」
不意に聞かれて、ドキッとした。
「うん...そうです。」
美香さんが慌てる。
「こら、実乃梨！」
「別に駄目とは言ってないじゃん！学校なんて行かなくていいよ〜、勉強たいぎいし。私も部活無かったら行ってないかもしんない。」
耕介は苦笑いするしかなかった。
「ははは...そうですね。」
美香さんが注意する。
「あんた、それとこれと何の関係があるん？」
実乃梨さんが我が意を得たりと続ける。
「そうそうそれ。耕介は向こう居た時もあんま学校行ってなかったらしいけどさ、環境変えたら余計に良くないんじゃない？二人してこっち戻ってくる必要があったの？ってこと。」
「畑やら田んぼやらするためでしょうが...まぁ、普通の耕平くんだったら、まず一人で始めて、安定してから耕介ちゃん呼びそうなもんじゃけど。」
「でしょでしょ。耕介にだって...教会の友達も居ただろうしさ。」
美香さんは黙り込んでしまった。二人は、色々と知らないことが多いらしい。説明をしないといけないが、兄からいつも言われている通り、まずは一番大事な結論から話さなければ。
「俺が...戻りたいって、言ったらしいんです。」
実乃梨さんがキョトンと目を開く。
「小さい頃、『いつかお父さんとお母さんの家に戻って暮らしたい』って言ったみたいなんです。だから、兄ちゃんは俺のために、頑張ってくれたんだと思います。」
「そう...だったんだ。」
美香さんが目を潤ませる。
「ええ子じゃねぇ...」
納得してもらえたらしい。でも、あともう一つだけ、訂正しておくことがあった。
「あと俺、教会には友達居ないですよ。」
実乃梨さんが疑問を口にする。
「え？どういうこと？やっぱ『神様信じない子は駄目〜』とかっていじめられてたの？」
天さんの教会は、元々児童養護施設ではない。たまたま遠縁の天さんが牧師をしていただけだ。つまり、周りの教会の子どもたちは信仰を持つ親の元で生まれた子。耕介自身は、信仰を否定はしないが、はっきりと信じてはいなかった。
だが、流石にそれでいじめるような心の狭い子は教会には居ない。
「いや、そんなことはないですよ！むしろ、心配してくれてたらしいです。ただ...なんとな〜く考え方が違うんだろなって感じて、俺のほうがあんまり仲良くしようとしなかったんです。それに、教会のスペース狭いのに人多くて入りづらかったから。」
実際、日曜礼拝の時は、聖殿には入らず、住んでいる宿舎でゲームをするか外の草むらを散歩していた。時々、礼拝後に教会のお兄さんに誘われて、キッズルームで他の子と一緒に卓球していたが、それ以上に関わろうとはしなかった。
「ああ...やっぱ宗教違うとそういう根本的な違いってあるよね。なんか、優しい牧師さんって言っても、ファンタジー小説みたいには上手く行かないもんだね。」
美香さんが答える。
「まぁそれでも、親戚だとしても子どもに信仰を押し付けない天さんは立派だと思うけどねぇ。ウチはちょ〜っとそれだけ心配してたけど、旦那が『博士のとこなら大丈夫だ』って言ったのは本当だったみたい。」
「へぇ〜、お父さんらしい変なあだ名だね。」
「それは...そうじゃね。なんか、父さんが好きだった小説の星読博士（ほしよみはかせ）に似とるらしいわ。」
「星読博士ね〜。案外センスあるじゃん。父さんよりちょっと若くてインテリイケメンって感じだし？割と好みかも。」
「あんた、そういうのは程々にしときんさいよ。あの人は神様一筋なんじゃけぇ。」
「分かってる分かってる！」
実乃梨さんはひらひらと手を振って美香さんをあしらうと、耕介に向き直る。
「そしたら、耕介はお友達居ないのか...こっちで同年代のお友達、出来るといいね。」
「そうですね...あ、でも、最近友達出来ましたよ！」
つい昨日、友達が出来たばかりだった。
「え！マジ！？良かったじゃん。なんていう子？私も知ってる子かなぁ？」
「ベッチって言います！！」
言った瞬間、実乃梨さんも美香さんも固まってしまった。
「え？ベッチ...？留学生さんか何か？でも、学校行ってないんじゃ...」
実乃梨さんが不思議なものを見るように耕介を見つめる。
「いや、フェアリーベッチのベッチです！草むらに居る妖精なんですよ。今度種撒きするんです。」
初めて出来た友達の話をすると、自然に笑みが溢れる。
...そんな耕介の笑顔とは裏腹に、実乃梨さんは答えあぐねてキョロキョロと視線を逸らし、美香さんは青ざめた顔をするばかりだった。
